# Dera Dastarkhwan – Bhakkar (Restaurant site + Urdu voice bot)

1. Install Node.js 18 or newer
2. `npm install`
3. `npm start`  → open http://localhost:3000

Keys live in `.env`. Restaurant facts for the bot live in `server.js` (KNOWLEDGE block).
Menu, phone, address on the page are in `public/index.html` – replace the sample data.
Microphone access needs https or localhost.
